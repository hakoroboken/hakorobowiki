環境構築をする際のPCのOSは**Ubuntu24.xx**を想定しています

---

## 環境構築とは

ソフトウェアは、**人が書いた「プログラミングコード」**を**コンパイラが「機械語」に翻訳**して作成されます。

コンパイラは翻訳者として、人が書いたコードを理解する必要があります。

ROS2を使う場合、コンパイラは**私達が書いたコードだけでなく、他者の書いたROS2コードを翻訳する必要がある**ので、その指示をコンパイラにする必要があります。

例えば以下のC言語コードにおいて、`printf`という関数は初期設定なら存在しません。`printf`は実際には`stdio.h`の中に定義されています。
`#include <stdio.h>`と書くことで、このメインファイルだけでなく、`stdio.h`も翻訳するように頼んでいるわけですね。

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, World!!\n");

    return 0;
}

```

ROS2を使うときにはこういった外部のコードの利用が多岐に渡ります。そのためにはコンパイラを対応したものに設定しなければなりません。

プログラミングするためのコンパイラを用意したりする行為を**環境構築**と言います。

---

## ROS2のための環境構築をする
**「なんか環境構築ってめんどくさそ〜」って思ったそこのあなた！**

大丈夫です。環境構築でやるべき動作をまとめたスクリプトがございます！

以下のコマンドを順番に実行するだけで環境構築は終わります

GitHubにある`hakorobo_setup`というリポジトリをPCにダウンロードします。
```sh
git clone https://github.com/hakoroboken/hakorobo_setup.git
```
これで`hakorobo_setup`というフォルダがあなたのPCにできたはずです。

以下のコマンドでそのフォルダ内に移動してください
```sh
cd hakorobo_setup
```

そして`ros2_jazzy_setup.sh`に権限（PCに色々な変更をするため）を与えます。
```sh
chmod +x ./ros2_jazzy_setup.sh
```

***あとは実行するだけ!!!!!!***
```sh
./ros2_jazzy_setup.sh
```
