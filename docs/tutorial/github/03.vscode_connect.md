## 確認してみる
最後にgitが入っているかの確認だけしておきましょう  
Windowsキーを押してpowershellと検索して、実行してください  

黒か青のウィンドウが出ると思うので、
~~~
git --version
~~~
と入れてみて反応があれば、成功です！

![git_check](./img/03.vscode_connect/23.git_check.png)

## ついでにちょっと設定しておこう
更に少しだけ設定を行いましょう  
~~~
git config --global user.name Githubのアカウント名
git config --global user.email GitHubに登録したメールアドレス@example.com
~~~
エンターを押しても何もでないと思いますが、それで大丈夫です

不安で確認したい人は、以下のコマンドで確認できます
~~~
git config --global --list
~~~

このように出てきたら、大丈夫です
~~~
user.email=GitHubに登録したメールアドレス@example.com
user.name=Githubのアカウント名
~~~

> 多分、user.nameはなんでもいいんですけど、  
> わかりやすくするためにアカウント名を推奨しています
