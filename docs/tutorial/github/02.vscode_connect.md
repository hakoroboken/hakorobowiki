# VSCodeでGitを使う

## Gitを使う方法について
ん？Gitってなんですか？？俺が知りたいのはGitHubなんですけど！！  
という方もいるかもしれないですね。  

一旦、GitHubがYoutube、Gitが動画だと考えるとわかりやすいと思います。  
簡単に言い直すと、GitとはGitHubで使われているシステムのことですね。  

あとで詳しく説明するので、ここは雰囲気で乗り越えてください。  

Gitの使い方についてですが、大きく分けて4つあると私は考えています。

1. VSCode上で使う
2. WebのGitHubを使う
3. ターミナルでコマンドラインを使う
4. GitHubのソフトを使う

それぞれのメリットとデメリットをまとめてみます。  
（100%正しい意見ではないと思うので気になることがあればぜひこのページに書き足してください）

### 1.VSCode上で使う
授業などですでにVSCodeを触っている人もいると思います。  
あのVSCodeの標準機能でなんとGitを使うことができます。  
メリットは、ある程度わかりやすいGUIがあること。つまりボタンをポチポチすることで操作できます。  
デメリットは、アカウントの認証がめんどくさいところ。かなりめんどくさいです。

### 2.WebのGitHubを使う
こちらは、先程作成したWebページを使用する方法です。  
メリットは、Webなので事前に環境を用意せずにボタンポチポチでできることです。  
デメリットは、毎回ファイルを選択してアップロードするのは普通に大変だということです。

### 3.ターミナルでコマンドラインを使う
これは、ハッカーとかが使ってそうな黒いウィンドウを出して、コードを打っていく方法です。  
メリットは、これも少しだけ環境を整えるのが簡単で一番複雑な操作ができます。  
デメリットは、ふつーに難しい。やりづらい。めんどくさい。

### 4.GitHubのソフトを使用する
正式名称は、GitHub Desktopですね。こちらを使用する方法です。  
メリットは、他の様々なソフトと同じように導入が楽です。  
(Windows,Mac,Linuxのすべて対応しているみたいです)  
デメリットは、少しだけ使いにくいところです。

私は、この4つを触ってきました。  
その上で、これまでは4のGitHubDesktopを1年生に教えてきました。  
理由は準備しやすいからです。  
exeファイルをダブルクリックすれば誰でも使えます。  
しかし、これにはとっても大きな問題があります。  
<span style="font-size: xx-large;">こいつ開く習慣がない</span>  
これは...単純ですがなかなか難しい問題ですね...

そこで、一番使う習慣がもともとあるものはなにか考えました。  
そうVSCodeですね。  
こいつはなんだかんだ開く機会が多いとは思います。  

## 準備するもの
では、VSCodeを入れていきましょう。  
すでに入れているよって人はサーッと飛ばしてもらって大丈夫です。

[code.visualstudio.com/download](https://code.visualstudio.com/download)から、インストーラーをダウンロードしてください。  
Windowsって書いてあるボタンをクリックすればダウンロードが始まると思います。
